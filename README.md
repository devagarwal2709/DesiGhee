## 📸 Overview

Desi Ghee replicates the atmosphere of a village *chaupal* at dusk—complete with string beds (*khat*), ambient hookah glows, drifting dust, and continuous rural anthems. 

The application runs purely in the browser using modern web standards without bundlers, heavy node runtimes, or client-side frameworks.
